Project Denver - ARM CPU JIT
============================
* Denver uses a Trace JIT called MTS to convert ARM instructions to native instructions. I maintain the Branch Profiling and Translation Cache code.
* Implemented branch-to-assert and lazy assert-to-branch logic. Boosts SPECINT by upto 15%
* Implemented Adaptive Branch Profiling framework to route hot translations to interpreter for a small time to regather branch weights and retranslate if weights shift. 
* Implementing logic to keep Translation Cache coherent with ARM Self Modifying Code
* Implemented various stubs to profile transitions to and from interpreted / optimized code
* Implementing Object Inlining for Javascript workloads to increase
prefetching and cache footprint. The goal is
to speculatively convert pointer chasing loads into runtime
constants for better cache/prefetch properties. We have hw support to
monitor memory ranges in 256B chunks for concurrent
modifications and rollback the speculative code. Work in progress..

Android Stack Perf Optimizations for Denver CPU
===============================================
* Linux Kernel : Implemented Large Page Suport for ARMv7 to automatically coalesce contig small pages into 64K pages. 5% IPC boost on SPECFP
* Linux Kernel : Implemented Thread Local Memory type in kernel. TLB invalidates to this memory are not broadcast to other cores. Patched Mozilla to use this memory type. Helps IPC by 20% on Google V8 Benchmark
* Implemented Memory Profiler Extension to QEMU to study page access patterns for apps.
